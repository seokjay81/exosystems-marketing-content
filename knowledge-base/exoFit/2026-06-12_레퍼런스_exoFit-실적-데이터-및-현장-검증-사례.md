## 활용 사례

### 활용 사례 1. 재활 트레이닝
- 목표: 회복 과정에서 남아 있는 보상 패턴과 근육 사용 불균형 확인
- 플로우: 측정(재활 운동 중 근육 사용과 움직임 상태 확인) → 확인(보상 패턴, 과활성화, 좌·우·건측/환측 차이 파악) → 피드백(자세, 운동 강도, 타깃 근육 사용 방식 조정) → 재측정(운동 전후 변화와 재활 결과 확인)
- 활용 포인트: 목표 근육 활성도 확인 / 좌우 및 건측·환측 비교 / 보상동작 및 과활성화 체크 / 재활 경과 모니터링

### 활용 사례 2. 웨이트 트레이닝
- 운동 중 근육 사용 신호를 직접 확인하여 목표 근육이 제대로 쓰이는 자세를 찾고 회원에게 더 적합한 운동 방법 설계
- 활용 포인트: 운동 중 실시간 활성도 확인 / 자세별 근활성도 비교 / 운동별 근활성도 비교 / 불필요한 근육 사용 확인

### 활용 사례 3. 선수 트레이닝
- 단순히 근육을 잘 쓰는 것뿐만 아니라, 언제, 얼마나, 어떤 패턴으로 근육을 사용하는지가 중요
- 활용 포인트: 근 협응 능력 확인 / 근사용 패턴 분석 / 트레이닝 방식에 따른 활성도 비교 / 비대칭 확인
