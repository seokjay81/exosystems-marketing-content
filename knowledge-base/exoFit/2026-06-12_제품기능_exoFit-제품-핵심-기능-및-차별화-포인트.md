# exoFit 제품 핵심 기능 및 차별화 포인트

> 제품: exoFit | 카테고리: 제품기능 | 등록일: 2026-06-12 | 출처: Sales_Note_V5.0

## exoFit 제품 정의
EMG(근전도) + IMU(움직임 센서) 기반의 AI 운동 역량 분석 솔루션

## 핵심 기능 4가지

### 기능 1. 7가지 피지컬 퍼포먼스 평가
exoFit 피지컬 퍼포먼스 평가는 OT 프로그램, 초기 상담, 정기 재평가 단계에서 활용 가능
- 평가 항목: 근력/근지구력 / 근피로도 / 좌우밸런스 / 유연성 / 보행분석 / 신체안정성 (총 7가지)
- OT·초기·정기 평가: 회원 상태를 감이 아니라 데이터로 파악, 첫 상담부터 신뢰도 있게 설명 가능
- 쉬운 결과 상담: 결과 리포트를 보면서 설명할 수 있어 회원이 자신의 상태와 운동 필요성을 쉽게 이해
- 운동 프로그램 설계 활용: 회원별 부족한 부분이 명확해져 운동 목표와 프로그램 방향을 빠르게 설정
- PT 전환 및 재등록 활용: 평가 결과와 변화 추이를 근거로 PT 필요성, 지속 관리의 가치를 자연스럽게 설득

### 기능 2. EMG 실시간 바이오피드백 모니터링
운동 중 근육 사용 상태를 실시간으로 확인해 코칭 정확도와 회원의 운동 이해도를 함께 높임
- 목표 근육 활성도 확인: 의도한 근육이 제대로 사용되는지 실시간 확인, 즉각적인 피드백 가능
- 보상 동작 및 과활성화 체크: 특정 근육이 과도하게 사용되거나 불필요한 보상 패턴 확인
- 동작 & 자세비교: 동작 수행에 따른 근육 사용 변화를 비교해 자세 교정과 운동 수행 개선 활용
- 워크플로우: 실시간 모니터링 → 결과 보고서 확인 → 보고서 비교 → 경과 확인

### 기능 3. IMU 실시간 바이오피드백 모니터링
- 가속도·각속도 확인: 가속도와 각속도, 각도를 실시간으로 확인하며 운동
- 움직임 범위 확인: 동작에서 나타난 최대 회전 범위(ROM)를 통해 자세 비교나 움직임 분석에 참고
- 움직임 궤적·안정성 분석: 동작이 한쪽으로 흔들리거나 불안정하게 수행되는지 파악

### 기능 4. 변화추이 관리
- 트레이너별 회원 관리: 트레이너별로 담당 회원들의 정보를 관리, 별도의 문서 불필요
- 운동 효과 시각화: 점수, 그래프, 변화 추이를 통해 회원이 자신의 개선 상태를 직관적으로 이해
- 맞춤 목표 재설정: 변화 데이터를 기반으로 다음 운동 목표와 프로그램 방향을 구체적으로 설정

## EMG vs IMU 기능 비교
**EMG (근전도):** 근육 활성 확인 / 타깃 근육 vs 보상 근육 / 좌우 밸런스 비교 / 근피로도 파악 / 실시간 근육 피드백 / 현장 설명·코칭 활용
**IMU (움직임 센서):** 자세 분석 / 움직임 패턴 확인 / 안정성 체크 / 반복 동작 변화 추적 / 비효율 동작 파악 / 동작 설명·피드백 활용
