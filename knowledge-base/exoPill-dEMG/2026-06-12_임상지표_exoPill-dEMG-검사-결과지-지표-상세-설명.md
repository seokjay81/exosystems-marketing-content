# exoPill dEMG 검사 결과지 지표 상세 설명

> 제품: exoPill-dEMG | 카테고리: 임상지표 | 등록일: 2026-06-12 | 출처: BD_동작분석_역동적근전도_설명자료_V1.0_250110

## 1. 일반 분석 지표

### 1.1 Standard EMG Analysis

**Averaged Mean of All Sections**
- 지표 의미: EMG 신호의 섹션별 평균을 구해 전체 신호의 평균적 경향
- 측정 목적: 세부적인 변동보다 전체적인 평균 경향 파악
- 해석 방법: 기준측의 평균 근활성 정도를 1이라고 할 때, 평가측의 비율(Ratio)이 1에 수렴할수록 좌우의 평균 근활성 정도가 균형을 이루고 있다고 판단

**Averaged Peak of All Sections**
- 지표 의미: EMG 신호를 여러 구간으로 나누고 각 구간의 최대 피크 값을 평균내어 근육 활동의 최고 활성화 수준 평가
- 측정 목적: 근육의 최대 수축력이나 피로도, 힘을 발휘하는 최대 순간 분석
- 해석 방법: 기준측의 피크 평균값을 1로 설정할 때, 평가측의 비율(Ratio)이 1에 가까울수록 좌우의 최대 근활성도가 균형을 이루고 있다고 판단

### 1.2 RVC Analysis
- 정의: 특정 근육의 자발적 최대 수축력(MVC)을 기준으로 근육의 활성도를 상대적으로 비교하는 지표
- 분석 방법: 각 근육의 활성도를 측정하여 MVC와 비교, 수치를 정규화하며 비율이 1에 가까울수록 좌우 균형적인 근육 활성화를 의미
- 활용: 근육 간 비대칭 문제 확인 및 재활 치료에서 타겟 근육의 회복 수준 평가

### 1.3 Gait Time Analysis

**Onset Timing Difference**
- 정의: 양쪽 다리의 유각기(swing phase) 시간 차이를 분석하여 보행 패턴의 대칭성 평가
- 분석 방법: 보행 중 각 다리의 근육이 활성화되는 시간 비교. 두 값이 유사할수록 대칭성과 안정성이 높음

**Activation Duration**
- 정의: 근육이 활성화되어 근수축을 유지하는 시간의 길이 측정
- 재활 활용: 손상된 근육의 회복 진행도 평가

## 2. 비대칭성 분석 지표

### 2.1 RMS 기반 분석
- 정의: 신호의 진폭을 평가하여 근육 활성도와 에너지를 추정
- 분석 방법: 신호의 제곱 평균 루트(RMS) 계산. RMS 값이 높을수록 근육 활동성이 강함
- 활용: 특정 동작에서 근육의 활성화 수준 확인

### 2.2 신호분석을 통한 상관계수
- 지표 의미: 두 신호 간의 관계를 평가하는 지표 (0~1 사이 값)
- 측정 목적: 양측 근육의 sEMG 신호 간의 상관성 평가
- 해석 기준:
  - r ≥ 0.8: 강한 상관관계
  - 0.6 ≤ r ≤ 0.8: 약간의 상관관계
  - 0.4 ≤ r ≤ 0.6: 약한 상관관계
  - r ≤ 0.4: 거의 상관이 없음

### 2.3 대칭성 지수
- 지표 의미: 근육 활성화 패턴의 대칭성 평가
- 해석 방법: 대칭성 지수가 0에 가까울수록 두 근육의 활성화 패턴이 균형을 이루고 있음

## 3. 근피로도 분석 지표

### 3.1 MDF/MNF 분석
- 정의: 주파수 데이터를 기반으로 근육 피로도를 평가하는 지표
- MDF (Median Frequency): 주파수 스펙트럼의 중간값
- MNF (Mean Frequency): 주파수 스펙트럼의 평균값
- 해석: 피로가 발생하면 근육 섬유의 변화로 인해 MDF와 MNF가 감소
- 활용: 좌우(건측/환측) 근육의 피로 정도 확인
