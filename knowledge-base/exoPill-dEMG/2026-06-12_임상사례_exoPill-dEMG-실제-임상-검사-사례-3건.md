# exoPill dEMG 실제 임상 검사 사례 3건

## 임상 검사 사례

### 사례 1: 내측 반월상 연골 뒤쪽 찢어짐

**환자 정보:** 남성, 35세 / 우측 내측 반월상 연골 뒤뿔(Medial Meniscus Posterior Horn) 손상 / 수술 없음
**검사방법:** 능동적 무릎 신전 운동 + 최대 등척성 수축 + Squat 3회

**결과 및 해석:**
1. 근활성도: 좌측 대퇴사두근의 평균 근활성도가 우측보다 62.2% 더 높음 → 우측 무릎 손상으로 인한 보상 작용(좌측 과활성화)
2. 활성 시간: 좌측 대퇴사두근의 활성 지속 시간이 우측보다 짧고, 동작 시작 시점도 좌측이 더 늦게 활성화
3. 비대칭성: RMS 기준 비대칭성 약 38.36%, 대칭성 지수 47.701 → 비대칭 상태
4. 근피로도: 좌우 MDF/MNF 정상 범위이나 우측이 약간 더 높은 값

**영업 포인트:** 감각으로는 발견하기 어려운 62% 좌우 근활성 불균형을 객관적 수치로 확인 → 치료 계획 수립의 근거

### 사례 2: 오른쪽 무릎 인공관절 수술 (TKA) 후 평가

**환자 정보:** 여성, 72세 / 우측 슬관절 퇴행성 골관절염 / 우측 슬관절 인공관절 치환술(TKA) 시행
**검사방법:** 6m 직선 경로 보행 중 근전도 측정

**결과 및 해석:**
1. 근활성도: 좌측 대퇴사두근의 평균 근활성도가 우측보다 높음 → 수술 후 우측 다리 근력 약화 및 보상 작용
2. 보행 대칭성: 좌우 대퇴사두근 간 비대칭성 약 40%, 우측 Onset Timing 지연 확인
3. 근피로도: 우측 MDF/MNF 값이 낮아 근피로가 좌측보다 높음 → 수술 후 근지구력 감소
4. 보행 패턴: 우측 다리 동작 수행 시간이 길어져 불균형한 움직임 → 기능 회복 미완료 확인

**영업 포인트:** TKA 수술 후 재활 진행 상태를 정량적으로 모니터링. 치료 계획 조정에 객관적 근거 제공

---

### 사례 3: 교통사고 후 좌골신경통

**환자 정보:** 여성, 58세 / 교통사고 후 좌측 좌골신경통(Sciatica) / 수술 없음
**검사방법:** 6m 직선 경로 보행 중 근전도 측정

**결과 및 해석:**
1. 근활성도: 좌측 대퇴사두근 RMS 기준 우측 대비 약 20% 감소, 좌측 햄스트링 Onset Timing 지연, 좌측 비복근 활성 감소
2. 동작분석: 좌측 Heel Strike 시점의 안정성 저하, 무릎 관절 각도 범위(ROM) 감소
3. 보행 분석: 좌측 입각기(stance phase) 시간 감소, 유각기(swing phase) 시간 증가 → 체중 부하 회피 경향
4. 비대칭성: 좌우 하지 근전도 활성도 비율 약 1.3:1, 좌측 MDF/MNF 12~18% 감소

**영업 포인트:** 통증 회피로 인한 비정상적 보행 패턴을 근전도로 객관화. 신경학적 손상 범위 확인에 활용
