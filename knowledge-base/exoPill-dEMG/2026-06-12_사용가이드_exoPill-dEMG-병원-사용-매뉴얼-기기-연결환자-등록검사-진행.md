# exoPill dEMG 병원 사용 매뉴얼 — 기기 연결·환자 등록·검사 진행

> 제품: exoPill-dEMG | 카테고리: 사용가이드 | 등록일: 2026-06-12 | 출처: exopill-demg.netlify.app_v0.7

## 5. 측정기기 연결

1. 좌측 [연결관리] 선택
2. 연결 가능한 기기 목록에서 사용할 크래들 선택 (반복 사용 시 자동 연결 옵션 가능)
3. 크래들 연결 후 모듈 연결 상태 확인 — 좌측 패널 상태 표시가 정상인지 확인

> **현장 안내:** 모듈 연결이 되지 않을 경우 크래들 전원 → 모듈 장착 상태 → 배터리 상태 → 블루투스 연결 상태 순서로 확인

---

## 6. 환자 등록 및 선택

1. **환자 선택** — 좌측 환자 목록에서 검사 대상 환자 선택 (이름/ID 검색 가능)
2. **신규 환자 등록** — [+] 버튼 클릭 후 ID, 이름, 성별, 생년월일, 신장, 체중 등 필수 정보 입력 후 [등록]

> 환자를 먼저 선택해야 검사 메뉴를 정상적으로 사용할 수 있습니다.
> ID와 생년월일은 중복 또는 오입력이 없도록 확인합니다.

---

## 7. 검사 시작 및 측정 진행

### 검사 유형 비교

| 구분 | 동작·근활성 검사 | 단측 기능성 검사 |
|------|----------------|----------------|
| 목적 | 동작 중 근활성 패턴 확인 | 건측 대비 환측 기능 차이 확인 |
| 측정 순서 | 설정한 동작 기준으로 측정 | 건측 측정 후 환측 측정 |
| 운영 포인트 | 좌우 또는 선택 채널 기준 측정 | 건측/환측 구분, 동일 조건 유지 |
| 결과 활용 | 좌우 근활성 패턴, 기능 회복 정도 확인 | 손상/수술/통증 부위의 기능 상태 및 회복 정도 확인 |

### 검사 진행 절차 (공통)
1. [근전도 검사] 선택 — 환자가 선택된 상태에서 진입
2. 검사 부위 선택 — 하체/상체/보행/단측 기능성 탭 선택 후 근육 부위 선택
3. 검사 동작 선택 — 까치발 들기, 서서 체중 옮기기, 한 발로 서 있기, 계단 오르내리기 등
4. 검사 설정 입력 — 세트 수, 횟수, 동작 시간, 세트 간/동작 간 휴식 시간 입력 후 [설정]

---

## 7-1. 동작·근활성 검사 측정 진행

1. **측정 화면 진입 및 신호 상태 확인** — 좌우 실시간 그래프 정상 표시 여부, 전극 채널 일치 확인
2. **측정 시작** — [측정 시작] 클릭 → 카운트다운 후 환자 동작 수행
   - 보상 움직임, 자세 흐트러짐, 전극 탈락 여부 확인
   - 신호 끊김 또는 비정상 시 측정 중단 후 재측정
3. **측정 완료 및 분석** — 그래프와 지표 확인 후 결과지 저장 또는 출력

> **교육 멘트 예시:** "지금부터 설정한 동작을 수행하면서 근육이 어느 시점에, 얼마나 활성화되는지 확인하겠습니다. 시작 신호가 나오면 안내드린 동작을 동일한 속도와 범위로 반복해 주세요."

---

## 7-2. 단측 기능성 검사 측정 진행

1. **건측/환측 기준 확인**
   - 건측: 통증이나 손상이 없거나 상대적으로 기능이 양호한 측
   - 환측: 통증, 손상, 수술, 기능 저하 등 평가 대상이 되는 측
2. **건측 먼저 측정** — [건측 측정 시작] 클릭, 카운트다운 후 동작 수행
   - 건측 측정값이 환측과 비교하는 기준값이 됨
3. **환측 측정** — 동일 조건으로 [환측 측정 시작] 클릭
   - 통증이나 불편감이 있는 경우 무리한 동작 강요 금지
4. **결과 분석 및 좌우 비교** — 양측 차이 확인 후 결과지 저장/출력

> **주의:** 측정 순서가 바뀌거나 양측 조건이 달라지면 결과 해석의 신뢰도가 낮아질 수 있습니다.
> **교육 멘트 예시:** "이 검사는 먼저 건강한 쪽을 기준으로 측정한 뒤, 같은 방식으로 불편한 쪽을 측정해 양측 차이를 확인하는 검사입니다."

---

## 8. 결과 확인·저장·출력

1. **요약 결과 항목 선택** — 결과지에 포함할 분석 항목 선택 (Averaged RMS Mean, RMS Mean of Each Section, Averaged RMS Peak, RMS Peak of Each Section 등)
2. **결과지 확인** — 검사 설정 정보, 측정 부위 좌우 균형, 분석 항목, 검사자/환자 정보 표시

### 저장/출력 버튼 기능

| 버튼 | 용도 | 현장 안내 문구 |
|------|------|--------------|
| 데이터 저장 | 측정 데이터를 저장 | "검사 데이터를 보관하기 위해 데이터 저장을 먼저 진행하겠습니다." |
| 결과 저장 | 결과지를 파일 형태로 저장 | "결과지는 설정된 폴더에 저장되며, JPG/PDF 형태로 저장할 수 있습니다." |
| 프린트 | 요약 또는 전체 결과지 출력 | "출력 범위를 확인한 뒤 결과지를 인쇄하겠습니다." |

---

## 9. 결과 비교

동일 환자의 이전 검사 결과와 현재 검사 결과를 비교하거나 특정 검사 결과를 나란히 확인할 때 사용

1. 메인 화면에서 [결과 비교] 선택 (환자 선택 상태에서)
2. 좌우 검사 목록에서 비교할 결과 각각 선택
3. 두 결과지를 나란히 확인하고 필요 시 확대, JPG, CSV, 프린트 기능 사용

## 10. 오류 대응 / FAQ

| 상황 | 확인 사항 | 대응 방법 |
|------|---------|---------|
| 측정기기가 검색되지 않음 | 크래들 전원, PC 블루투스, 모듈 장착 상태 | 크래들 재연결 → 프로그램 재실행 → PC 블루투스 재확인 |
| 모듈이 연결되지 않음 | 모듈 배터리, 크래들 장착 방향 | 모듈을 크래들에 다시 장착하고 충분히 충전 후 재시도 |
| 신호가 불안정함 | 전극 부착 상태, 피부 접촉 | 피부 상태 확인 후 전극 재부착, 측정 중 모듈 고정 |
| 환자 등록 버튼이 비활성화됨 | 필수 입력값 누락 | ID, 이름, 성별, 생년월일 등 필수 항목 모두 입력 |
| 결과 파일을 찾기 어려움 | 결과지 저장 경로 | 설정 → 결과지 관리에서 저장 경로 확인 |
| 출력물이 원하는 범위와 다름 | 프린트 범위 설정 | 상단의 프린트 범위에서 요약/전체 결과지 선택 후 출력 |
| 최신 버전 다운로드 필요 | 현재 버전 vs 최신 버전 | [설정] > [버전 관리]에서 확인 후 다운로드 (검사 종료 후 진행) |

## 11. 현장 체크리스트

### 검사 전
- PC와 소프트웨어 실행 상태를 확인했다
- 크래들 및 1~4번 모듈 연결 상태를 확인했다
- 환자 정보가 정확히 등록되어 있다
- 전극 부착 부위와 피부 상태를 확인했다
- 결과 저장 경로와 프린터 상태를 확인했다

### 검사 중 / 검사 후
- 검사 부위와 동작이 목적에 맞게 선택되었다
- 세트 수, 횟수, 동작 시간이 올바르게 설정되었다
- 측정 중 신호와 자세를 확인했다
- 측정 완료 후 분석하기를 진행했다
- 결과 저장 및 출력까지 완료했다

> **교육 권장 방식:** 신규 사용자에게는 "기기 연결 → 환자 등록 → 검사 설정 → 측정 → 결과 저장"을 1회 시연한 뒤, 동일 절차를 직접 수행하게 하는 방식이 가장 효과적입니다.
