# exoPill dEMG 병원 사용 매뉴얼 — 전체 사용 흐름 및 준비

> 제품: exoPill-dEMG | 카테고리: 사용가이드 | 등록일: 2026-06-12 | 출처: exopill-demg.netlify.app_v0.7

## 개요
exoPill dEMG 병원 사용 매뉴얼 (v0.7)
본 매뉴얼은 병원 검사 담당자가 exoPill dEMG 소프트웨어를 이용해 환자 등록, 검사 설정, 측정, 결과 확인 및 저장을 진행할 수 있도록 정리한 병원용 사용 안내서입니다.

---

## 1. 전체 사용 흐름 (6단계)

| 단계 | 항목 | 내용 |
|------|------|------|
| ① | 검사 환경 확인 | 검사자/기관 정보, 결과 저장 경로, S/W 버전 관리 상태 확인 |
| ② | 측정기기 연결 | 크래들과 측정 모듈의 연결 상태 및 배터리 상태 확인 |
| ③ | 환자 선택 | 검사 대상 환자 선택 또는 신규 환자 정보 등록 |
| ④ | 검사 유형 및 조건 설정 | 검사 유형, 검사 부위, 측정 동작, 좌우 기준, 세트/횟수/시간 설정 |
| ⑤ | 측정 진행 | 카운트다운에 맞춰 환자가 동작 수행, 측정 완료 후 결과 확인 |
| ⑥ | 결과 확인 및 저장 | 결과지 확인 후 필요한 형식으로 저장·출력·비교 |

**운영 포인트:** 단측 기능성 검사는 건측을 먼저 측정한 뒤 환측을 측정합니다.

---

## 2. 사용 전 준비

### 필수 준비물
- exoPill 크래들 및 측정 모듈
- 검사용 PC 또는 노트북
- 하이드로겔 전극
- 환자 기본 정보

### 검사 전 확인사항
- 측정 모듈 배터리 및 블루투스 연결 상태 확인
- 전극 부착 부위의 피부 상태 확인
- 환자가 안전하게 동작할 수 있는 공간 확보
- 결과 저장 경로와 프린터 연결 상태 확인

> **주의:** 측정 중 전극이 들뜨거나 모듈 연결이 불안정하면 신호 품질이 저하될 수 있습니다. 측정 전 부착 상태와 연결 상태를 반드시 확인하십시오.

## 4. 기본 설정

1. **우측 상단 [설정] 클릭** — 병원 정보, 측정 설정, 결과지 저장 방식, 버전 관리 화면 확인
2. **병원 정보 및 검사자 정보 확인** — 검사자명, 병원명, 병원 로고 설정 (결과지에 표시됨)
3. **결과지 관리** — 결과지 저장 경로 지정, JPG/PDF 등 저장 방식 확인
4. **버전 관리** — 현재 버전과 최신 버전 여부 확인, 필요 시 다운로드

> **운영 권장:** 납품 또는 교육 전에는 [설정] > [버전 관리]에서 최신 버전 사용 여부를 먼저 확인합니다.
> **주의:** 검사 중에는 업데이트를 진행하지 않습니다.
